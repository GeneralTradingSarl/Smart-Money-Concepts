How to install the Smart Money Concepts indicator in MetaTrader 5

Two minutes, no account, no DLL. Use the .ex5 to run it straight away, or compile the .mq5 if you want to read or change the code.

1. Install the .ex5 (ready to run)

  1. Download SmartMoneyConcepts.ex5 from the release page or the button above.
  2. In MetaTrader 5, open File › Open Data Folder. A file explorer window opens on the terminal’s data folder.
  3. Open MQL5, then Indicators, and copy SmartMoneyConcepts.ex5 there. You can also make a subfolder, for example Indicators/SMC.
  4. Back in MT5, in the Navigator (Ctrl+N), right-click Indicators and choose Refresh. Restarting MT5 works too.
  5. Drag SmartMoneyConcepts onto a chart, set the options in the Inputs tab and press OK.

Copy the file into the data folder opened from MT5, not into the program folder under C:\Program Files. Each broker’s terminal has its own data folder.

2. Compile the .mq5 (source code)

  1. Put SmartMoneyConcepts.mq5 in MQL5/Indicators exactly as above.
  2. Open MetaEditor with F4 from MetaTrader 5, then open the file from the Navigator on the left.
  3. Press Compile (F7). The result should read 0 errors, 0 warnings and a SmartMoneyConcepts.ex5 appears next to the source.
  4. Refresh the Navigator in MT5 and attach the indicator.

The source is a single file of about 2,300 lines with no include and no external library. It is saved as UTF-8 with a byte order mark, which MetaEditor needs to read the accents in the header.

3. Settings and templates

The inputs keep the names, defaults and groups of the TradingView original: Smart Money Concepts, Real Time Internal Structure, Real Time Swing Structure, Order Blocks, EQH/EQL, Fair Value Gaps, Highs & Lows MTF, Premium & Discount Zones and Alerts, plus a MetaTrader group with the number of bars to compute and the label font. Every input is described in the settings reference.

  • Keep your setup: right-click the chart, Templates › Save Template. Apply it to any other chart in one click.
  • Every new chart: save the template as default and every new chart opens with the indicator already on it.
  • Colours and transparency: each Pine colour with transparency became two inputs, a colour and a transparency from 0 to 100, because MetaTrader colours have no alpha channel.

4. Alerts, push notifications and email

The 16 alert conditions of the original are in the Alerts group: internal and swing BOS and CHoCH (bullish and bearish), internal and swing order block breakouts, equal highs, equal lows, bullish and bearish fair value gaps. Tick the ones you want, then choose how you are told:

  • Popup: the MetaTrader alert window with a sound (on by default).
  • Push notification: enter your MetaQuotes ID (shown in the settings of the MetaTrader 5 mobile app) in Tools › Options › Notifications on the desktop terminal.
  • E-mail: set up your mail server in Tools › Options › Email.
  • Alert on bar close only (on by default) waits for the candle to close, like a once-per-bar-close alert on TradingView. Turn it off to be told once per bar, as soon as the condition appears.

5. Troubleshooting

The indicator is not in the Navigator

The file is probably not in the data folder of this terminal. Open it again with File › Open Data Folder from the same MT5, check the file is in MQL5/Indicators, then Refresh. Make sure you are using MetaTrader 5: an .ex5 does not run in MetaTrader 4.

Nothing, or very little, is drawn

Structure needs history. Scroll the chart back to load more bars, or raise Max bars in chart in Tools › Options › Charts. Check that Bars to compute in the MetaTrader group is 0 (all bars) or large enough. Some features are off by default, as on TradingView: swing points, swing order blocks, fair value gaps, daily, weekly and monthly levels, premium and discount zones.

It does not look like my TradingView chart

The logic is identical, so differences come from the data: your broker’s candles are not TradingView’s candles (different feed, different session hours, different time zone for daily bars). Different candles give different swings. On the same bars, the output is the same object for object, as the proof shows.

The chart is slow on very long histories

Set Bars to compute to a few thousand bars. Structure further back rarely matters for trading.

Compilation errors with the .mq5

Make sure the file was not re-saved by another editor without its UTF-8 byte order mark, and that MetaEditor is up to date (Help › Check for updates, or update the terminal).
