02 · What it draws

The whole script. Every input, every alert.

Nothing was simplified. Same input names, same defaults, same groups as the TradingView original.

Market structure: BOS and CHoCH

Break of Structure and Change of Character on two scales: internal structure (5-bar swings) for entries, swing structure (50 bars by default) for the bigger picture. Optional confluence filter.

Internal and swing order blocks

Bullish and bearish order blocks filtered by ATR or cumulative mean range, mitigated on High/Low or on Close, each with its own count limit.

Equal highs and lows

EQH and EQL: liquidity resting at the same level, with an adjustable threshold and confirmation length.

Fair value gaps

Three-candle imbalances on the chart timeframe or a higher one, with an automatic threshold and adjustable extension.

Premium, equilibrium, discount

The current swing range split into premium, equilibrium and discount zones, updated as the range grows.

Strong and weak highs and lows

The trailing swing extremes, labelled strong or weak from the current trend, plus HH, HL, LH and LL swing points.

Previous day, week and month

PDH and PDL, PWH and PWL, PMH and PML levels, each with its own colour and line style.

Trend candles and 16 alerts

Candles coloured by the internal trend. Every alertcondition of the original becomes an MT5 alert: popup, push notification or email.

Historical or Present, Colored or Monochrome

The same display modes as the original. Present mode keeps only the latest structure for a clean chart.

03 · Under the hood

Where MetaTrader forced a different mechanism, never a different result

A port is only as good as its edge cases. Four places where MT5 works differently from Pine, and what the port does about it.

Measured on TradingView, reproduced in MQL5

// Pine: absolute tolerance of 1e-10 0.1 + 0.2 == 0.3 // true 1 + 0.9e-10 > 1 // false 1 + 1e-10 > 1 // true // SmartMoneyConcepts.mq5, line 417 #define PINE_EPS 1e-10 bool Gt(const double a, const double b) { return a - b > PINE_EPS; } bool Lt(const double a, const double b) { return b - a > PINE_EPS; }
01

Pine’s real-time rollback

The forming bar is computed on a throwaway copy of the state and discarded at the next tick. Only closed bars are committed, exactly like Pine in real time.

02

Pine’s object limits

Labels, lines and boxes go through an in-memory collection that enforces Pine’s limit of 500 of each, oldest deleted first, then mirrored on the chart.

03

Real transparency

MT5 objects have no alpha channel, so boxes are painted on a transparent canvas with true alpha blending. Each color.new(c, t) becomes a colour input plus a transparency input.

04

Pine’s float tolerance

Pine compares numbers with an absolute 1e-10 tolerance, so 0.1 + 0.2 == 0.3 is true. Without it, one candle where the confluence filter compares 0.05 to 0.05 fired one CHoCH too many. The port reproduces it.

04 · Install

Running in under a minute

  1. Download SmartMoneyConcepts.ex5 (or the .mq5 if you want to read or change the code).

  2. In MetaTrader 5, open File › Open Data Folder, then MQL5 › Indicators, and drop the file there.

  3. Back in MT5, right-click Indicators in the Navigator and choose Refresh.

  4. Drag SmartMoneyConcepts onto any chart. Settings and alerts are in the Inputs tab.

Using the .mq5? Open it in MetaEditor (F4) and press Compile (F7). It compiles with 0 errors and 0 warnings. Full installation guide and troubleshooting →

09 · FAQ

Questions traders ask

Is it really free?

Yes. The compiled .ex5 and the full .mq5 source are free to download, use and modify for non-commercial purposes. No account, no email, no licence key. Donations are optional.

Is this the official LuxAlgo indicator?

No. It is an independent, unofficial MQL5 port of LuxAlgo’s open-source Smart Money Concepts script, published under the same CC BY-NC-SA 4.0 licence with attribution. LuxAlgo does not endorse it.

Is it really identical to TradingView?

On the test set, yes: 100% of labels, lines, boxes and candle colours matched across four configurations and two tick-by-tick replays. The only difference is the price of weekly and monthly levels, which TradingView reads from its own W and M bars. You can check it in the proof viewer or re-run the bench from GitHub.

Does it repaint?

It behaves exactly like the original. Structure is confirmed on closed bars; the forming bar is recalculated on every tick and only committed when it closes. Swing points are confirmed after their lookback length, as in Pine, so their labels appear a few bars after the pivot.

Which markets and timeframes does it work on?

Any symbol and timeframe MetaTrader 5 can chart: forex, gold (XAUUSD), indices, crypto and stocks. Daily, weekly and monthly levels use your broker’s D1, W1 and MN1 data.

Can I sell it or publish it on the MQL5 Market?

No. The licence forbids commercial use, for the original and for this port. You can share it, modify it and use it for your own trading, keeping the attribution and the same licence.

Can I use it in an Expert Advisor?

Yes: with Color Candles on, an EA can read the trend from the colour buffer (buffer 4) with iCustom. If you need clean signal buffers for BOS, CHoCH or order blocks, or a complete EA built on it, I can make an EA-ready version for you.

Is there an MT4 version?

Not yet. An MQL4 version can be built on request.

Can I donate with another coin?

Any asset on the TRON network can go to the TRON address, and any BEP-20 token on BNB Smart Chain to the BNB address. Always check the network before sending: a wrong network means lost funds.
