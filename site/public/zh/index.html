02 · 它绘制什么

完整脚本。每个参数，每个警报。

没有任何简化。参数名称、默认值和分组都与 TradingView 原版相同。

市场结构：BOS 与 CHoCH

在两个尺度上识别结构突破（BOS）与性质转变（CHoCH）：内部结构（5 根K线的波段）用于入场，波段结构（默认 50 根K线）用于把握大方向。可选共振过滤。

内部与波段订单块

看涨与看跌订单块，可按 ATR 或累积平均波幅过滤，按最高/最低价或收盘价判定失效，各有独立的数量上限。

等高点与等低点

EQH 与 EQL：停留在同一价位的流动性，阈值和确认长度均可调。

公允价值缺口（FVG）

三根K线形成的失衡区，可取当前周期或更高周期，带自动阈值和可调延伸。

溢价区、均衡区、折价区

将当前波段区间划分为溢价区、均衡区和折价区，随区间扩大而更新。

强/弱高点与低点

当前波段的极值，按趋势标为强或弱，并标出 HH、HL、LH、LL 波段点。

前一日、前一周、前一月

PDH 与 PDL、PWH 与 PWL、PMH 与 PML 水平线，各有独立的颜色和线型。

趋势K线与 16 种警报

K线按内部趋势着色。原版的每个 alertcondition 都变成 MT5 警报：弹窗、推送通知或电子邮件。

Historical / Present，Colored / Monochrome

与原版相同的显示模式。Present 模式只保留最新的结构，图表更清爽。

03 · 技术细节

MetaTrader 要求换一种机制，但结果从不改变

移植的质量取决于边界情况。以下是 MT5 与 Pine 运行方式不同的四个地方，以及移植版的处理方式。

在 TradingView 上实测，在 MQL5 中重现

// Pine: absolute tolerance of 1e-10 0.1 + 0.2 == 0.3 // true 1 + 0.9e-10 > 1 // false 1 + 1e-10 > 1 // true // SmartMoneyConcepts.mq5, line 417 #define PINE_EPS 1e-10 bool Gt(const double a, const double b) { return a - b > PINE_EPS; } bool Lt(const double a, const double b) { return b - a > PINE_EPS; }
01

Pine 的实时回滚

正在形成的K线在一份临时状态副本上计算，下一个跳动时丢弃。只有已收盘的K线才会被写入，与 Pine 的实时行为完全一致。

02

Pine 的对象上限

标签、线条和方框先经过内存中的集合，执行 Pine 每类 500 个的上限，最旧的先删除，然后同步到图表上。

03

真正的透明度

MT5 对象没有 Alpha 通道，因此方框绘制在透明画布上并进行真正的 Alpha 混合。每个 color.new(c, t) 变成一个颜色参数加一个透明度参数。

04

Pine 的浮点容差

Pine 比较数字时使用 1e-10 的绝对容差，所以 0.1 + 0.2 == 0.3 为真。没有它，有一根共振过滤比较 0.05 与 0.05 的K线会多出一个 CHoCH。移植版完整重现了这一点。

04 · 安装

一分钟内即可运行

  1. 下载 SmartMoneyConcepts.ex5（如需阅读或修改代码，也可下载 .mq5）。

  2. 在 MetaTrader 5 中打开 文件 › 打开数据文件夹，进入 MQL5 › Indicators，把文件放进去。

  3. 回到 MT5，在导航器中右键点击 指标，选择 刷新。

  4. 把 SmartMoneyConcepts 拖到任意图表上。设置和警报在 输入参数（Inputs）选项卡中。

09 · 常见问题

交易者常问的问题

真的免费吗？

是的。编译好的 .ex5 和完整的 .mq5 源代码都可以免费下载、使用和修改，仅限非商业用途。无需账户、无需邮箱、无需许可证密钥。捐赠完全自愿。

这是 LuxAlgo 官方指标吗？

不是。这是 LuxAlgo 开源脚本 Smart Money Concepts 的独立非官方 MQL5 移植版，以相同的 CC BY-NC-SA 4.0 许可发布并保留署名。LuxAlgo 并未认可它。

真的和 TradingView 完全一样吗？

在测试数据上是的：四种配置和两次逐笔回放中，100% 的标签、线条、方框和K线颜色都一致。唯一的差别是周线和月线水平的价格，因为 TradingView 读取的是它自己的 W 与 M K线。您可以在对比查看器中检查，或在 GitHub 上重跑测试。

会重绘吗？

行为与原版完全相同。结构在K线收盘后确认；正在形成的K线每个跳动都会重算，只在收盘时写入。波段点在其回看长度之后才确认，与 Pine 一样，所以标签会在枢轴点之后几根K线才出现。

适用于哪些市场和周期？

MetaTrader 5 能显示的任何品种和周期：外汇、黄金（XAUUSD）、指数、加密货币和股票。日、周、月水平使用您经纪商的 D1、W1 和 MN1 数据。

我可以出售它或发布到 MQL5 Market 吗？

不可以。许可证禁止商业用途，原版和本移植版都一样。您可以分享、修改并用于自己的交易，但须保留署名并使用相同许可。

可以在 EA 中使用吗？

可以：开启 Color Candles 后，EA 可以通过 iCustom 从颜色缓冲区（缓冲区 4）读取趋势。如果您需要 BOS、CHoCH 或订单块的干净信号缓冲区，或基于它的完整 EA，我可以为您制作适合自动交易的版本。

有 MT4 版本吗？

暂时没有。可以按需定制 MQL4 版本。

可以用其他币种捐赠吗？

TRON 网络上的任何资产都可以发到 TRON 地址，BNB Smart Chain 上的任何 BEP-20 代币都可以发到 BNB 地址。发送前务必确认网络：选错网络意味着资金丢失。
